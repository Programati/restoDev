# auth — Contratos del módulo

## Entidad

Autenticación y sesión de usuarios mediante Supabase Auth.

## Actions

| Action         | Descripción       | Permiso     | Equivalente API | Ficha                      | Estado              |
| -------------- | ----------------- | ----------- | --------------- | -------------------------- | ------------------- |
| `loginAction`  | Inicia una sesión | Público     | No aplica       | [`login.md`](./login.md)   | Action implementada |
| `logoutAction` | Cierra la sesión  | Sin permiso | No aplica       | [`logout.md`](./logout.md) | Action implementada |
