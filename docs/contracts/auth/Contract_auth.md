# auth — Contratos del módulo

## Entidad

Autenticación y sesión de usuarios mediante Supabase Auth.

## Actions

| Action         | Descripción       | Permiso     | Equivalente API | Ficha                                        | Estado              |
| -------------- | ----------------- | ----------- | --------------- | -------------------------------------------- | ------------------- |
| `loginAction`  | Inicia una sesión | Público     | No aplica       | [`Contract_login.md`](./Contract_login.md)   | Action implementada |
| `logoutAction` | Cierra la sesión  | Sin permiso | No aplica       | [`Contract_logout.md`](./Contract_logout.md) | Action implementada |
